Bounty: [Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c)

A deadpan TV weather forecast for a city that does not exist:

> Tonight in Port Widdershins, a high of 19 degrees, light rain, and one cloud that has been following Mrs. Abernathy since 1987.

Invented city plus concrete numbers (19 degrees, 1987) with the twist in the final words: a single cloud that has been following one named resident since 1987. Deadpan broadcast tone, nothing explained.

## Run it

```sh
node main.ts
```

`main.ts` writes the single line to `/output/entry.txt` (127 characters, inside the 1–160 gate). Node 22 standard library only, fully deterministic: the same bytes on every run, no network, no clock, no randomness.
